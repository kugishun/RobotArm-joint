# neutral姿勢と現在姿勢の比較表示

## 最新仕様：範囲校正後にneutralを設定

以下の過去の5cm・10度の復帰条件は撤去した。開始時は `Begin / restart range calibration` で計測用の仮基準を取得し、上・前・右の範囲を登録する。ロボット範囲の計算がReadyになったら楽な手の姿勢を取り、`Set current pose as neutral and start` を押す。この瞬間の位置・向きをneutralにして追従する。以前の仮基準へ戻す必要はない。

保存した人体の範囲端点を維持し、各軸の最小・最大値を新しいneutral基準に換算する。新しいneutralも範囲に含める。ロボット側の基準点と推定範囲は変更しない。範囲計算の完了、有効な入力、ロボット姿勢・工具設定の整合性は引き続き開始条件とする。

緑のneutral表示は追従開始時から表示。位置差・回転差は参考値として表示し、OK/OUTSIDEと半径5cmの球は表示しない。開始前は新しいneutralを登録する案内を表示する。今回もコマンド実行環境のエラーでコンパイル・Play確認は未実施。

2026-09-30追加。人・ロボット範囲校正のCapture neutralで登録した右手姿勢を、現在の右手姿勢と比較する。

- 操作パネル：NEUTRAL/CURRENTのワールド位置（m）、ワールドEuler角（度）、校正した操作座標での位置差（右・上・前、cm）を表示。
- 判定：位置は3次元距離5cm以内、回転はQuaternionの最短回転角10度以内。個別にOK/OUTSIDEを表示する。表示するEuler角を単純に引いて判定しているわけではない。
- Gameビュー：保存位置に緑のNEUTRAL、現在の右手に紫のHAND INPUTを表示。MainCameraの画角内にある点のみ表示。
- Sceneビュー：GizmosをONにすると、両姿勢のXYZ軸、保存位置を中心とした半径5cmの球、現在位置との接続線を表示。

姿勢比較は3姿勢の登録中から表示する。実際に開始できるのはWorkspace calibrationがReadyになり、手の位置・向きの条件を満たし、ロボット側の開始条件にも問題がない場合。位置の球に入っていても回転差が10度を超えていれば開始できない。

範囲外の警告とは別に、基準姿勢へ戻るための表示を追加したもの。今回の変更では開始判定の許容幅と、姿勢追従OFFでも回転差を要求する既存の仕様を変えていない。

ローカルコマンド実行がhelper_unknown_errorで失敗したため、今回の変更後のコンパイル・Play動作は未確認。UnityでPlayを止めてコンパイル後に再開し、再度Capture neutralから確認する。

## 追従開始ボタン

`Start tracking from neutral` を範囲校正パネルに常時表示する。既定はグレーアウトで、校正がReady、手とロボットの入力が有効、工具・制限・姿勢の条件が維持され、手の位置がneutralから5cm以内かつ回転差10度以内のときだけ有効になる。条件から外れると再び無効になる。自動では追従開始せず、ユーザーがボタンを押して開始する。

ボタンの下に無効理由を表示する。開始処理も同じ判定をクリック時に再実行する。追従開始後はボタンを無効にしてTracking is already activeと表示するが、neutralから離れたことだけで追従を停止することはない。今回も実行環境エラーのためコンパイル・Play検証は未実施。
